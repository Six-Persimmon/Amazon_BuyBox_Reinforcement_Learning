Official Repository for "Personalization, Consumer Search, and Algorithmic Pricing"
This repository contains all code and scripts associated with the paper Personalization, Consumer Search, and Algorithmic Pricing. The experiments conducted are simulation-based, and no empirical data has been utilized.

# Environment Setup

Python Version: Ensure you have Python ≥ 3.8.3.
Conda Environment: Create a new conda environment.
Dependencies: Install all required packages using the provided requirements.txt.


# Experiments
To generate the experimental results, run the following command in your terminal:
sh shell.sh


# Figures
To produce all the figures presented in the paper, execute:
python figure.py


# Tables
To generate the tables included in the paper, run:
python table.py
